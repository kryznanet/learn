Manajemen Akses

Perubahan role dan status disimpan melalui fungsi database terproteksi dan disinkronkan ke RBAC.
Super Admin
Kelola user, role, sistem, dan seluruh konten.
Admin
Kelola operasional konten.
Editor
Review dan kelola materi sesuai permission.
Penulis / Pemateri
Buat dan edit materi sendiri.
Viewer
Akses terbatas untuk melihat.

Pengguna Belajar

Admin dan Super Admin dapat menambah serta mengedit akun pengguna biasa (role Pengguna). Pengelolaan staf tetap mengikuti aturan RBAC staf.
