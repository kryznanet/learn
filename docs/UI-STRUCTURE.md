## Website Publik

- Materi

## Kelola Materi
- Daftar Materi
- Tulis / Edit Materi
- Riwayat Versi
- Riwayat Aktivitas Materi

## Administrasi
- Dashboard
- Kelola Pengguna
- Riwayat Aktivitas Sistem
- Pengaturan

## Role
- Penulis: membuat dan mengelola materi sesuai hak akses.
- Editor: meninjau dan memproses materi sesuai hak akses.
- Admin: mengelola materi dan operasional.
- Super Admin: mengelola seluruh sistem dan pengguna.
- Viewer: akses lihat terbatas untuk kompatibilitas akun lama.

## Catatan teknis
Nama tabel, permission, dan endpoint internal tetap menggunakan istilah teknis yang sudah berjalan. Perubahan nama di dokumen ini adalah istilah UI agar mudah dipahami pengguna.
