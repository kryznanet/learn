Mengenal IPv4

IPv4 (Internet Protocol version 4) adalah protokol yang digunakan untuk memberikan alamat unik kepada setiap perangkat di jaringan internet.

Struktur IPv4

IPv4 terdiri dari 32-bit yang dibagi menjadi 4 oktet (kelompok 8-bit). Setiap oktet dipisahkan oleh titik dan memiliki nilai antara 0 sampai 255.

Contoh: 192.168.1.1

Kelas IPv4

  • Kelas A: Untuk jaringan skala besar (0-127).
  • Kelas B: Untuk jaringan skala menengah (128-191).
  • Kelas C: Untuk jaringan skala kecil/rumahan (192-223).

Subnet Mask

Subnet mask digunakan untuk membedakan bagian network ID dan host ID. Contoh paling umum untuk kelas C adalah 255.255.255.0.
