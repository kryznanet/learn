Cara Cek IP di Windows 11

Ada beberapa cara untuk mengecek alamat IP perangkat Anda di Windows 11, mulai dari cara grafis hingga menggunakan perintah cepat.

1. Melalui Command Prompt (Cara Tercepat)

  1. Buka Start menu, ketik cmd, lalu tekan Enter.
  2. Ketik perintah berikut dan tekan Enter:
    3. ipconfig
  3. Cari bagian IPv4 Address pada adapter Wi-Fi atau Ethernet yang Anda gunakan.

2. Melalui Pengaturan Windows

  1. Buka Settings (tekan tombol Win + I).
  2. Pilih menu Network & internet.
  3. Klik pada Properties dari koneksi Wi-Fi atau Ethernet Anda.
  4. Informasi IP Address akan tampil di bagian bawah.
